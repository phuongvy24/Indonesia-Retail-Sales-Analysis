# Indonesia-Retail-Sales-Analysis
This project analyzes retail sales performance in Indonesia using the Global Superstore dataset. The analysis focuses on identifying sales trends, profit performance, customer behavior, and regional business insights through Python-based data analytics and visualization techniques.

---

## Objectives
- Analyze monthly and quarterly sales/profit trends
- Compare sales and profit across different States and Cities
- Identify top-performing product categories and sub-categories
- Explore customer purchasing behavior and regional performance
- Generate business insights through data visualization

---

## Dataset
- Dataset: Global Superstore
- Focus Area: Indonesia
- File Format: `.xls`

---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Certain regions generated high sales but relatively low profit margins
- Technology products contributed significantly to overall revenue
- Sales performance varied across different States and Cities
- Customer purchasing behavior showed clear differences between segments and categories

---

## Conclusion
This project demonstrates how data analysis and visualization can be used to explore retail business performance and support data-driven decision-making. The analysis provides insights into sales trends, profitability, and regional performance within the Indonesia market.
